# 研究工作台增强功能设计

日期：2026-10-05

## 目标

在不修改选股策略、扫描条件、评分阈值和既有数据文件的前提下，为“策略实验室”增加搜索、个人观察池、评分解释、策略比较、市场宽度、个股研究、信号提醒和数据源状态展示。

## 边界

- 网站名称继续使用“策略实验室”。
- 不修改 `intraday_scanner.py`、策略注册表、策略实现及扫描定时任务。
- 新功能只读取当前已有的日报、盘中快照、行情缓存、资金和复盘结果。
- 观察池、提醒已读状态保存在浏览器 `localStorage`，不同浏览器互不影响，不引入登录系统。
- 后端返回的评分解释必须解释已有分数，不能重新计算或覆盖选股分数。
- 任一新增数据源缺失或损坏时，页面要标记“缺失/过期”，并继续展示其他可用模块。

## 架构

### 后端聚合层

新增 `tools/research_workspace.py`，负责纯读取和聚合：

- 从最新全市场行情快照计算上涨、下跌、平盘、涨停、跌停、中位涨幅和市场温度。
- 汇总日报、盘中、资金、板块和连板文件的更新时间及健康状态。
- 合并日报、盘中累计记录和行情快照，提供股票代码/名称搜索。
- 汇总单股基础信息、当前信号、历史策略统计及已有评分明细。
- 根据浏览器传来的观察池代码返回最新信号提醒。

`api_server.py` 只增加读取型接口，不改变原接口行为：

- `GET /api/workspace/overview`
- `GET /api/stocks/search?q=...`
- `GET /api/stock/<code>/research`
- `GET /api/workspace/alerts?codes=...`

### 前端增强层

新增 `static/research_workspace.js`，避免继续扩大首页内联脚本。页面增加：

- 顶部全局股票搜索框和结果浮层。
- “个人观察”主导航，按浏览器保存自选股。
- 股票卡片上的收藏和研究入口；点击卡片原有 K 线行为保持不变。
- 右侧个股研究抽屉，展示行情、策略命中、评分依据和近期 K 线。
- 策略复盘里的策略比较器，最多比较 4 个看涨策略。
- 市场概览条，展示市场宽度、涨停强度和数据源健康数量。
- 提醒中心，提示观察池股票进入日报或盘中信号；已读状态本地保存。
- 数据源状态面板，明确正常、过期、缺失以及实际使用的文件。

## 数据语义

### 市场宽度

使用最新 `cache/tushare_a_stock_spot_*.csv`：涨幅大于 0 为上涨，小于 0 为下跌，其余为平盘；涨幅不低于 9.5% 计入涨停强度，跌幅不高于 -9.5% 计入跌停。若快照不是当前日期，结果仍可展示，但必须标记为过期。

### 评分解释

盘中股票优先展示已有 `scoreBreakdown`。日报股票只列出已有总分、命中策略数量、所属信号类别及可验证的展示字段，并明确标记“展示解释，不重新评分”。

### 策略比较

只读取 `strategyDashboard.historyRows` 中的看涨策略，比较历史胜率、平均涨幅、样本数和复盘天数；不参与实时选股或排序。

### 个股研究

从日报和盘中缓存中找出同一股票的最新记录，返回当前行情、日线、命中策略、评分明细、信号来源和更新时间。字段缺失时显示“暂无”，不得使用无日期的旧数据冒充最新数据。

### 提醒

提醒仅针对当前浏览器观察池。日报命中与盘中命中分别生成稳定 ID，前端用 ID 记录已读；提醒是页面内提示，不发送短信、邮件或系统推送。

## 失败与降级

- JSON/CSV 文件读取失败只影响对应模块，并在数据源状态中显示错误。
- 没有全市场快照时，市场宽度返回空统计而非 500。
- 搜索空关键词返回空结果；非法股票代码返回 400 或 404。
- `localStorage` 不可用时观察池退化为当前页面内存，页面其他功能保持正常。
- 新前端脚本加载失败时，原页面导航、策略过滤、盘中刷新和图表继续可用。

## 验收标准

1. 搜索代码或名称可找到日报、盘中或最新行情快照里的股票。
2. 用户可收藏/取消收藏，并在“个人观察”中看到自己的股票。
3. 研究抽屉展示信号、评分依据、K 线和数据更新时间。
4. 可同时比较 2 至 4 个策略，清晰显示胜率、平均涨幅和样本数。
5. 页面显示市场宽度、涨停数及数据源健康状态。
6. 观察池股票出现日报或盘中信号时生成可读提醒。
7. 缺少任意数据文件时接口返回可解释的降级结果，既有页面仍可使用。
8. 网站名称、策略输出和原有 API 兼容性保持不变。
