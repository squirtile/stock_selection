# 放量启动—缩量回踩—二次突破策略 V1
研究日期：2026-09-09  
案例：闽东电力（000993.SZ）  
状态：已完成日线单例计算核验；未完成全市场回测、分钟级触发核验或真实成交验证。

## 1. 结论与适用范围

本策略不是“预测某股明天必然涨停”，而是把一次具体走势拆成两个阶段：
完整日线收盘后形成候选池，下一交易日出现符合条件的盘中突破才发出交易观察信号。

第一版固定研究“最近五日中的前三日启动、后两日回踩”（3+2结构）。
这是从已知成功案例提出的待验证假设，不是事前预测记录。
未来应在其他股票、其他日期及冻结规则后的未见样本中检验，不能把参数专门调到只适配这一只股票。

基础池在公式和示例 Python 脚本之外处理：沪深主板非ST普通A股，排除创业板、
科创板、北交所、停牌、退市整理、上市不足120个交易日及无正常涨跌幅限制的证券。
若把“首板”作为严格标签，最近若干日是否涨停应通过历史涨停价字段逐日判断，
不能简单以涨幅9.95%作为通用边界。示例脚本只输出 shape_signal，不代表上述过滤已完成。

## 3. 日线候选条件：在 t 日收盘后计算

t：候选池形成日，本例为9月8日。
启动段：t-4、t-3、t-2；回踩段：t-1、t。
启动段之前的五日：t-9至t-5。
以下为初始研究阈值，不是回测最优参数。

| 条件 | 定义 |
|---|---|
| A1 位置和波动 | C[t]/过去20日最低价≤1.20；过去20日最高价/最低价≤1.30 |
| A2 三日启动 | C[t-2]/C[t-5]-1介于3%和12%；启动三日中至少两日收盘上涨 |
| A3 放量 | 启动三日均量≥启动前五日均量×1.80 |
| A4 两日回撤 | C[t]<C[t-1]≤C[t-2]；C[t]≥C[t-2]×0.95 |
| A5 缩量 | 回踩两日均量≤启动三日均量×0.75；V[t]<V[t-1] |
| A6 保持结构 | C[t]≥MA10≥MA20；最近两日最低价≥启动第一日收盘价×0.99 |

所有条件同时成立才输出日线形态候选。`ths_daily_formula.txt` 与 `daily_signal.py`
实现的是同一套形态条件。Python算术及截断测试已通过；同花顺公式未在客户端编译验证。
日线公式只适用于完整收盘数据，不能在盘中把最新价伪装成收盘价后仍宣称是昨日候选池。

样例计算：9月8日全部形态条件成立，详见 `sample_check.json`。
这只是样本内复现，不是提前预测成功的证明。

## 4. 下一交易日盘中触发：规则设计，尚未核验

在 t 日收盘后冻结参考位，只在下一交易日使用。下一交易日结束即过期，重新计算，
不能把旧候选池和旧突破位无限保留。

本例的参考位：
- 昨日高点10.53：早期观察位。
- 最近两日最高价10.68：第一版正式突破参考。
- 最近五日最高价11.05：上一轮冲高压力位，并非无条件买点。
- 最近两日最低价10.32：结构支撑。
- 支撑下方0.5%缓冲约10.27：用于研究的初始结构止损参考，不保证成交。

建议把盘中信号定义为以下条件的交集：

1. 股票已在前一晚的候选池。
2. 一根已经结束的5分钟K线收盘价 > 冻结的两日最高价。
3. 当前累计成交量 / 过去5个交易日同一交易时刻累计成交量均值 ≥ 1.5。
   分钟数据需按交易时段对齐，不能以今日全日最终成交量作为盘中可知数据。
4. 已结束5分钟K线收盘价位于截至该时刻的当日VWAP上方。
   VWAP=累计成交额/累计成交股数，手数必须先换算为股数，不能遗漏100倍单位关系。
5. 发出信号后，用后续可得的1分钟行情或逐笔行情检查成交价格与流动性。
   不允许按产生信号那根5分钟K线的开盘价回填成交。
6. 下一笔可执行买价的当日涨幅不超过7%，且距离计划止损价不超过买价的5%。
   两项都是初始回测风控假设，不是收益保证。
7. 已封涨停、没有可执行卖盘或价格跳过允许区域时，记录“有形态但无可执行买点”，不虚构成交。

若复用既有“日线—30分钟—5分钟—1分钟”工作流，30分钟结构和板块强度先作为记录/评分项，
不要未经回测就增加多个硬条件。盘口只做辅助确认，不单凭委买、委卖或瞬时大单触发。

本次未取得9月9日涨停前完整分钟行情，因此没有验证上述条件是否同时发生，
也没有证明10.68附近存在实际可成交的买入机会。
价格越过一个参考价，不等于本策略一定能买到。

## 5. 风险与退出的初始研究规则

以假设成交10.70、止损参考10.27为例，计划价格风险约4.02%，未计滑点和费用。
若等到11.06才成交而仍沿用10.27止损参考，计划风险约7.14%，超过5%的准入阈值，应拒绝该笔交易。
不能为了允许高位追入而事后抬高止损、伪造更小的风险。

普通A股当日新买入份额不能当日卖出。止损条件只能在持仓可卖时执行；若次日低开跳过
止损价，或跌停无可执行买盘，必须按实际可成交价格和日期记账。最大损失可能明显超过计划值。

第一轮模拟可固定采用：
- 初始止损参考=两日回踩低点×0.995，按最小报价单位处理。
- R=实际买入价-初始止损参考；可卖后达到买入价+2R则退出。
- 若均未触发，买入日之后第5个交易日14:50后首个可执行价格退出。
- 同一根粗粒度K线同时触及止损和止盈时，不能默认先止盈；需更细行情或保守处理。
- 计入佣金、印花税、过户费、滑点、限价无法成交和资金占用。费率按实际适用规则与券商条件输入。
以上仅是固定基准，尚未验证哪个退出方案有效。

## 6. 回测应该回答的问题

不能只在涨停股中寻找共同外观。应从当时的全部合格股票中生成信号，包括后来不涨停、
突破失败、停牌及退出市场的股票，保留当时的ST状态、上市状态和价格限制信息。

分别统计：
候选池数量；候选次日/三日内触板率及相对基础概率的提升；
盘中触发率；实际可成交率；成交后1/3/5日净收益；
最大不利波动、最大回撤和不同市场阶段表现。

固定3+2只是首版。可预先登记少量邻近参数，例如2—4日启动、1—3日回踩，
然后按时间做训练/验证拆分并保留真正未见样本。不得筛选出最高收益参数后只报该结果。
本文件不提供胜率、年化收益或盈利承诺。

## 7. 运行与文件

Python仅使用标准库，无需安装第三方包。解压后运行：

```bash
python daily_signal.py --as-of 2026-09-08
python daily_signal.py --as-of 2026-09-08 --output my_check.json
```

`daily_data.json`：网页整理的22日样例及来源、精度说明。  
`daily_signal.py`：日线形态核验，不联网、不连接账户、不下单。  
`ths_daily_formula.txt`：同花顺日线候选公式文本。  
`sample_check.json`：本次实际运行结果。  
`validation.txt`：测试范围说明。

输入必须是同一股票、连续交易日、统一价格和成交量口径的完整日线。
脚本拒绝重复日期、非法OHLC、非正成交量和缺失的完整目标日期；
不会替你验证交易日历、停牌间隔、除权因子、证券资格或源数据是否错报。
